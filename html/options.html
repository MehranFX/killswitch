🌐 Wildcard Support

You can use wildcards (*) in domain patterns:

  • *.example.com - Matches all subdomains (api.example.com, www.example.com, etc.)
  • example.* - Matches all TLDs (example.com, example.org, example.net, etc.)
  • *.example.* - Matches all subdomains and TLDs
  • example.com - Exact domain match only

Examples:

  • *.google.com → matches: maps.google.com, drive.google.com, docs.google.com
  • *.github.io → matches: username.github.io, project.github.io
  • api.* → matches: api.example.com, api.test.org
